# 图标来源

本目录 SVG 来源：

1. **Ant Design Icons**（`@ant-design/icons-svg@4.4.2`，阿里 / [iconfont.cn](https://www.iconfont.cn/) 同系，MIT）— 通用 UI 图标  
2. **vscode-icons**（经 Iconify：`file-js` / `file-css` / `file-ts` / `file-vue` / `file-json` / `file-scss`）— 文件树可辨识类型图标  

接入：经 `src/components/AppIcon.vue`；类型映射见 `src/utils/fileTreeIcon.ts`。业务页面勿再手绘 path。
